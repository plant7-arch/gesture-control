Step 1: Update the system and confirm your session
bash
sudo apt update && sudo apt full-upgrade -y
echo $XDG_SESSION_TYPE        # should print: wayland

Reboot if the upgrade installed a new kernel.

Step 2: Install system packages
bash
sudo apt install -y build-essential git curl wget \
  v4l-utils ffmpeg playerctl \
  libgl1 libglib2.0-0t64 libxcb-cursor0

What these are for:

build-essential compiles python-evdev.
v4l-utils and ffmpeg inspect and test the camera.
playerctl lets you control media players later.
libgl1, libglib2.0-0t64 and libxcb-cursor0 are needed for OpenCV’s preview window.

If apt says libglib2.0-0t64 doesn’t exist, use libglib2.0-0 instead.

Step 3: Check the webcam
bash
v4l2-ctl --list-devices                         # find your camera, usually /dev/video0
v4l2-ctl -d /dev/video0 --list-formats-ext      # look for MJPG and the highest fps at 640x480
ffplay -f v4l2 -input_format mjpeg -video_size 640x480 -i /dev/video0

The ffplay window should show live video. Press q to close it.

Note down two things from the formats list: whether MJPG is available, and the best fps at 640×480. If the camera exposes several /dev/video* nodes, the first one listed under it is normally the right one.

If you get “Permission denied”, check that you’re in the video group:

bash
groups | grep video || sudo usermod -aG video $USER   # then log out and back in
Step 4: Set up virtual input (uinput)

This is the step that lets your program move the mouse and press keys on Wayland.

bash
# Load the uinput kernel module now and on every boot
sudo modprobe uinput
echo uinput | sudo tee /etc/modules-load.d/uinput.conf

# Give a dedicated group access to /dev/uinput
sudo groupadd -f uinput
sudo usermod -aG uinput $USER
echo 'KERNEL=="uinput", GROUP="uinput", MODE="0660", OPTIONS+="static_node=uinput"' \
  | sudo tee /etc/udev/rules.d/99-uinput.rules
sudo udevadm control --reload-rules && sudo udevadm trigger

Now log out and log back in (or reboot) so the new group takes effect. Then check:

bash
groups | grep uinput          # should list uinput
ls -l /dev/uinput             # should show: crw-rw---- root uinput
